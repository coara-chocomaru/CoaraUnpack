# Coara Unpack

私のアプリ、Coara Unpack は、Android の boot イメージや ramdisk を展開して、中身を確認・編集し、もう一度イメージに戻すためのアプリです。

難しい設定をしなくても使えるように、基本は「ファイルを選ぶ → 必要なところを編集する → リパックする」という流れになっています。

## できること

- `boot.img`、`vendor_boot.img` などの展開とリパック
- ramdisk の展開とリパック
- kernel、ramdisk、DTB、recovery_dtbo、bootconfig などの取り出し
- `info.txt` によるヘッダー情報やイメージ構成の確認・一部編集可
- gzip、LZ4、XZ、LZMA、bzip2 などの圧縮形式の読み込み・作成
- AVB1 署名付きイメージの再署名
- AVB2 の VBMeta とフッター情報の保持

Android boot header v0～v4 と vendor_boot v3/v4 に対応していますが全てのimgの動作を保証する訳ではありません。

## 基本的な使い方

### boot イメージを展開する

1. 「imgをアンパック」を選びます。
2. `boot.img` などのファイルを選びます。
3. 必要に応じてオプションを使用
4. 展開が終わると、日時+ファイル名で Download フォルダ内に作業用フォルダができます。

作業用フォルダには、元の `original.img`、構成情報の `info.txt`、kernel や ramdisk などが入ります。イメージの種類によって、作成されるファイルは異なります。

「ramdiskも中身まで全部展開する」を選ぶと、ramdisk のファイルも別フォルダに展開します。「圧縮を解かずにそのまま取り出す」を選ぶと、対応する圧縮データを展開せずに保存します。

### boot イメージをリパックする

1. 「imgをリパック」を選びます。
2. 先ほど作成した作業用フォルダを選びます。
3. 圧縮形式などのオプションを確認して、「やってみる」を押します。
4. 完成した `.img` は、選んだ作業用フォルダの中に 日時+repack.img名で保存されます。

`kernel`、`ramdisk.cpio`、`dtb` など、変更したいファイルを編集してからリパックしてください。ヘッダー情報の一部は `info.txt` から編集できます。リパックには `info.txt` が必要なので、削除しないでください。

圧縮形式の「auto」は、元の形式を基本にして作成します。

### ramdisk を展開・リパックする

1. 「ramdiskを展開」を選び、ramdisk ファイルを指定します。
2. 展開先にできたフォルダの `rootfs` を開き、ファイルを編集します。
3. 「ramdiskをリパック」を選び、そのフォルダを指定します。
4. 圧縮形式を選んで実行します。「auto」なら元の形式を使います。
5. 日時名でリパックされたファイルを"ramdisk.cpio"必要な名前にリネームします
6. リネームしたramdiskファイルを.imgのアンパックフォルダ(作業フォルダ)内に上書き配置します。
7. それでimgをリパックすればramdiskを編集した.imgが生成されます。

※「全ファイルの権限を0777にする」は、すべてのファイルやフォルダの権限を変更するオプションです。必要な場合だけ使ってください。

## AVB1 の鍵について

AVB1 署名付きイメージをリパックすると、作業用フォルダ内の鍵を使って自動的に再署名します。

鍵がまだ無い場合は、次のファイルを自動生成してフォルダに保存します。

- `testkey.pk8`：秘密鍵
- `testkey.x509.pem`：X.509 証明書

次回からは保存された鍵を使います。自分の鍵を使う場合は、この2ファイルを両方差し替えてください。別のファイル名を使う方法や、複数の鍵を置く場合の指定方法は [AVB1_KEYS.md](AVB1_KEYS.md) にまとめています。


## AVB2 について

AVB2 イメージでは、元の `vbmeta.bin` と `avb_footer.bin` を作業フォルダに保存し、リパック時にはVBMetaを保持してフッターの配置情報を更新します。

## 作業中の画面について

処理中は進捗とログが表示されます。アプリを閉じていても、作業はフォアグラウンドサービスで続行します。画面または通知からキャンセルできます。

ログは長押しで選択でき、「ぜんぶコピー」からまとめてコピーできます。完了時に表示される出力パスをタップしてコピーすることもできます。

## 使う前に確認しておいてほしいこと

- 元のイメージは必ず別の場所にもバックアップしてください。
- このアプリはイメージの展開・作成を行うもので、端末への書き込みやフラッシュは行いません。
- 作成したイメージが端末で起動するかどうかは、機種、パーティション構成、ブートローダーの設定、署名鍵などによって変わります。
- lzop 圧縮の ramdisk は対応していません。
